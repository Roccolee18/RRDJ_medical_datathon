# RRDJ_medical_datathon
A showcase of our weekend working at the National Canadian Medical Datathon!

## Data Source
This project uses the diabetes readmission dataset sourced from:

[Beata Strack, Jonathan P. DeShazo, Chris Gennings, Juan L. Olmo, Sebastian Ventura, Krzysztof J. Cios, and John N. Clore, “Impact of HbA1c Measurement on Hospital Readmission Rates: Analysis of 70,000 Clinical Database Patient Records,” BioMed Research International, vol. 2014, Article ID 781670, 11 pages, 2014.](https://doi.org/10.1155/2014/781670)
